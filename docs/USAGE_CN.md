# 当前版本使用说明

## 当前网站账号切换

在正常的 HTTP 或 HTTPS 页面打开扩展。解锁 Cookie 保险库后，弹窗会显示当前网站已保存的账号；点击“保存当前账号”会本地捕获该网站 Cookie 并加密保存。GitHub 页面可使用页面公开的 `user-login` 元数据建议账号名称。

点击“切换”会先删除当前网站 Cookie，再写入选中账号的 Cookie，并刷新当前标签页。账号名称、站点关联和 Cookie 内容都在加密桶或加密目录中，服务端不可读取。

## 设置与总密码

设置页提供全部桶的重命名和删除。会话 token 仅保存在 `chrome.storage.session`，浏览器完全退出后需要重新登录。

如需更换总密码，进入设置页的危险操作，选择“删除全部加密数据并重置总密码”，并输入 `DELETE` 确认。该操作会永久删除服务器中该账号的所有加密桶（包括目录元信息），但不会删除 OAuth 登录账号；下次保存账号时即可设置新的总密码。

## 配额、导入与导出

新注册用户默认有 10 MiB 加密存储配额。设置页的导入和导出均使用明文 JSON，必须先解锁总密码。导入的数据会先在本地校验，再立即使用当前总密码加密上传；服务端不会收到明文。明文导出文件包含会话凭据，请仅保存在可信位置并在使用后删除。
